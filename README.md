## D-Day Counter
중요한 기념일이나 시험일 등 목표일까지 남은 날짜를 터미널에서 간편하게 계산하고 관리할 수 있는 초간단 파이썬 스크립트입니다.
로컬 환경에서 빠르고 가볍게 일정을 체크할 수 있습니다.

기능
- 등록된 D-Day 목록 및 남은 일수(D-Day) 실시간 계산 조회
- 새로운 이벤트 추가 (YYYY-MM-DD 형식)
- 불필요한 이벤트 삭제
- JSON 파일을 통한 데이터 자동 저장

설치 및 실행 방법
1. 레포지토리 클론 git clone https://github.com/username/DDayCounter.git cd DDayCounter
2. 스크립트 실행 Bash셸 -> python dday.py
3. 입력값
- 메뉴 선택 (1: D-Day 목록, 2: D-Day 추가, 3: 삭제, 4: 종료)
- 이벤트 이름 및 날짜 입력 (YYYY-MM-DD)

사용예시:
- --- [1] D-Day 목록 [2] D-Day 추가 [3] 삭제 [4] 종료 ---
- 선택: 2
- 이벤트 이름: 수능
- 날짜 (YYYY-MM-DD): 2026-11-19

결과:
- --- [1] D-Day 목록 [2] D-Day 추가 [3] 삭제 [4] 종료 ---
- 선택: 1
- - D-190 : 수능 (2026-11-19)

요구사항
- Python 3.x
- 추가 라이브러리 없음 (표준 라이브러리 `datetime`, `json`, `os`만 사용)
